# WidgetWesizer

## Download

**[Download the latest APK](https://github.com/originalkiser/widgetwesizer/releases/latest/download/WidgetWesizer.apk)**

All versions are on the [Releases page](https://github.com/originalkiser/widgetwesizer/releases).

### Installing on Android

1. Open the download link above on your phone.
2. Open the downloaded `WidgetWesizer.apk`.
3. If prompted, allow your browser or file manager to install unknown apps.
4. Tap **Install**. Newer releases install as updates over older ones.

## How releases are built

Every push to `master` runs `.github/workflows/build.yml`, which builds a signed release APK
and publishes it as a new GitHub Release tagged `v1.0.<build number>`.
